## Sửa trang

Có hai cách:

**1. Sửa trực tiếp trên trang** — mở trang, bấm nút *Sửa trực tiếp* ở góc dưới,
click vào chữ để sửa, xong bấm lưu. Trình duyệt sẽ hỏi chọn file để ghi đè
(cần Chrome hoặc Edge). Sửa xong nhớ đẩy file mới lên GitHub thì bản online mới đổi theo.

**2. Sửa file rồi đẩy lên** — sửa `index.html` hoặc `du-an-ca-nhan.js` bằng VS Code, rồi:

```bash
git add -A
git commit -m "Cap nhat portfolio"
git push
```

Khoảng 1–2 phút sau là bản online cập nhật.

**Riêng mục 07 — Dự án cá nhân** thì chỉ sửa trong `du-an-ca-nhan.js`, đừng sửa trực tiếp
trên trang, vì mục đó được vẽ lại mỗi lần mở trang. Xem `HUONG-DAN-DU-AN-CA-NHAN.md`.
