## Sửa trang

Bản online này chỉ để xem, không có nút sửa. Việc sửa làm ở bản trên máy:

1. Sửa `portfolio-tuyetquynh-2026-11-11.html` (hoặc `du-an-ca-nhan.js` nếu là mục dự án cá nhân)
2. Chạy `python tao-ban-public.py` để dựng lại thư mục này
3. Đẩy lên:

```bash
git add -A
git commit -m "Cap nhat portfolio"
git push
```

Khoảng 1–2 phút sau là bản online cập nhật.

**Riêng mục 07 — Dự án cá nhân** chỉ sửa trong `du-an-ca-nhan.js`, xem `HUONG-DAN-DU-AN-CA-NHAN.md`.
